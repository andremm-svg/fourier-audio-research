# Research notes

## Research question
How can Fourier analysis help interpret sound signals, and how can detected sound events trigger automated audio-video recording?

## Paper
*Transformata Fourier: Un instrument esential in analiza sunetelor* - Student Scientific Communications Session, 2025.

## Proposed workflow
1. Capture sound measurements with Arduino.
2. Detect relevant sound events using a threshold.
3. Send status messages to a connected computer over serial.
4. Use Python to control audio and video capture.
5. Stop and save the recording when silence is detected or a time limit is reached.

## Concepts covered
- Fourier series and transforms
- Frequency-domain interpretation of acoustic signals
- Embedded signal monitoring
- Serial communication between Arduino and Python
- Event-driven media capture
